# Lootr More Tactical Loot 1.1.21

Bilanciamento per Nuovo Ordine / Minecraft 1.20.1 Forge, costruito sulla 1.1.20.

## Armi ancora più rare
Il roll globale delle armi nelle casse Lootr passa dal 12% all'8%.

Tutto il resto del loot resta invariato: munizioni, accessori e silenziatori, zaini e upgrade Sophisticated Backpacks, kevlar/armature, materiali Create e template Superb Warfare.

Restano inoltre valide tutte le esclusioni precedenti per RPG-7, minigun e cecchini pesanti/anti-materiel.

Il marker passa a 1121.
