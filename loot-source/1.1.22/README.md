# Lootr More Tactical Loot 1.1.22

Aggiornamento per Nuovo Ordine / Minecraft 1.20.1 Forge.

## Munizioni
Il pool AMMO delle casse Lootr viene sostituito interamente con munizioni Superb Warfare:

- `superbwarfare:handgun_ammo`
- `superbwarfare:rifle_ammo`
- `superbwarfare:shotgun_ammo`
- `superbwarfare:sniper_ammo`
- `superbwarfare:heavy_ammo`

Le munizioni TaCZ, incluse quelle dei gunpack rappresentate tramite `tacz:ammo` + NBT `AmmoId`, non vengono piu estratte dal pool.

Armi, attachment, silenziatori, zaini, upgrade, kevlar/armature, Create e template Superb Warfare restano invariati rispetto alla 1.1.21.

Il marker passa a 1122.
